Round 1 — Design Tokens & Specs

Blind & Build Competition Rules

01

Observation / Memorize Phase

Participants get a fixed observation window (30s for Round 1, 45s for Round 2, and 1 minute for Round 3) to study the website. No screenshots, no inspect element, and no note-taking (or as permitted by rules). Study the hierarchy, colors, spacing, and interactive components.

02

The Blindfold / Build Phase

Once the preview timer expires, the target website is concealed. Participants have 30–60 minutes (30m for Round 1, 45m for Round 2, and 1 hour for Round 3) to recreate the webpage from memory using standard HTML5, CSS3, and JavaScript.

03

Difficulty Progression

Round 1 (Easy): Clean product landing page. Tests fundamental Flexbox, cards, and typography.
Round 2 (Medium): Fintech platform with glassmorphism, 3D floating credit card, and pricing switch.
Round 3 (Hard): High-density AI cloud telemetry dashboard with live streaming, pipeline visualizer, and code tabs.

04

Judging & Victory

Judges evaluate fidelity using the built-in Pixel-Diff Overlay tool. Closest layout alignment, color reproduction, and interactive functionality wins the round!
